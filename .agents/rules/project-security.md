# Project Security Rule — Root L Flux

- Nunca inserir credenciais, tokens, chaves de API ou endereços privados sensíveis no código-fonte ou na documentação.
- Carregar configurações sensíveis exclusivamente via variáveis de ambiente.
- Não executar comandos destrutivos ou mutações em serviços externos sem aprovação explícita do usuário.
